Before you start

Tested on One UI 6. This is an advanced guide for rooted Samsung devices. Depending on your device and ROM, you may need additional steps to get Air Actions working.

You will need root access, and an S Pen Pro.

1. Install Air Command as a privileged system app

Download Samsung Air Command 6.1.40.1 from APKMirror. The APK supports Android 9 and later.

Note that newer Air Command releases can fail to install with this error:

Failure [-3001: INSTALL_FAILED_REJECTED_BY_BUILDTYPE]

If 6.1.40.1 also gives you the same error, try a different version, but keep in mind the version that will be installed should contain S Pen Pro support.

With Magisk, use a systemless module that places the APK under /system/priv-app/. Install and enable the module in Magisk, then restart so Android loads Air Command as a privileged system app. Other root setups have their own ways to install privileged system apps.

2. Grant the Nearby devices permission

Open Settings → Apps and select Air Command. If it’s hidden, turn on Show system apps. Open Permissions → Nearby devices and tap Allow.

3. Spoof S Pen support

Back up /system/etc/floating_feature.xml before editing it. Preserve the file’s original owner, group, and permissions when you make changes.

Find SEC_FLOATING_FEATURE_FRAMEWORK_CONFIG_SPEN_GARAGE_SPEC. If the element already exists, set unbundled_spec=remote in its value and keep the other entries. If it’s missing, add this element inside the XML file’s root element.

<SEC_FLOATING_FEATURE_FRAMEWORK_CONFIG_SPEN_GARAGE_SPEC>type=inbox, bundled=false, unbundled_spec=remote</SEC_FLOATING_FEATURE_FRAMEWORK_CONFIG_SPEN_GARAGE_SPEC>

4. Set the S Pen options with ADB

Using ADB, run these commands:

adb shell settings put system pen_usage_detected 1
adb shell settings put system pen_digitizer_enabled 1

5. Restart and pair your S Pen Pro

Restart the device, then reopen /system/etc/floating_feature.xml and confirm the change persisted.

Open Settings → Advanced features → S Pen → Air Actions. If everything was successful, you will be able to pair an S Pen Pro and start using Air Actions.

For full control over Air Actions, use PenStar.
