Start with a working Tasker task

Install Tasker separately and create the task you want to run. Test it directly in Tasker first. This gives you a working action before you connect it to a button or gesture.

Then set up KeyStar or PenStar. Allow Run Tasker Tasks access when the mapping app requests it, and follow any Tasker prompt needed to permit the external task. Other permissions can depend on what the task itself does.

Assign a task to a KeyStar button

  1. Open the button configuration. For a starting example, use Volume Up or Volume Down.
  2. Choose a context and trigger. Use General and a double press for a simple first mapping.
  3. Select Tasker Task. Choose the task you have already created and tested.
  4. Save and enable the mapping. Try the button press and check that the task runs as expected.

If the task runs inside Tasker but not from the button, review Tasker access and check that the KeyStar service, button mapping, and intended context are active.

Assign a task to a PenStar gesture

  1. Create an App Action. Choose the apps where you want the gesture to run the task.
  2. Select a gesture. For example, choose Double Click.
  3. Choose Tasker Task. Select your existing task and save the collection.
  4. Try it inside a selected app. Confirm that PenStar and the collection are enabled, then perform the gesture.

PenStar needs a Samsung device with Air Actions and Android 8.1 or later. If the gesture itself is not detected, check the S Pen connection and PenStar's required permissions before changing the task.

Switch configurations with the Tasker plugin

Both apps provide Tasker plugin support for Enable, Disable, Backup, and Restore. You can use these operations in a Tasker workflow to change which configuration is active.

For example, you could keep a separate saved configuration for Power Saving mode and use a Tasker profile to restore it when that mode becomes active. Decide which configuration should be restored when leaving the mode as well.

Configuration restore changes your app setup. Keep a backup of the configuration you want to return to, and try the workflow with a small set of mappings first.

Start or stop the mapping service with an intent

For an alternative to the plugin, enable Control KeyStar using intents or Control PenStar using intents in the relevant app's settings. The app accepts broadcast intent actions to start or stop its service.

  • KeyStar: com.threestars.keystar.action.START_SERVICE and com.threestars.keystar.action.STOP_SERVICE
  • PenStar: com.threestars.penstar.action.START_SERVICE and com.threestars.penstar.action.STOP_SERVICE

See KeyStar intent control and PenStar intent control for the developer's examples.
